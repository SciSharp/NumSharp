THIRD-PARTY NOTICES for NumSharp.Interop.OpenBLAS
============================================================================

NumSharp.Interop.OpenBLAS itself is licensed Apache-2.0, like the rest of NumSharp.

This package additionally REDISTRIBUTES prebuilt OpenBLAS shared libraries as
NuGet runtime assets (runtimes/<rid>/native/). They are the unmodified artifacts
published on PyPI by the openblas-libs project as 0.3.31.22.0
-- the very same binaries NumPy 2.4.2 bundles in its own wheels, which is what makes
NumSharp's matrix products bit-identical to that NumPy's.

Bundled components and their licenses:

  LAPACK                                 BSD-3-Clause (the "modified BSD" of netlib LAPACK)
                                         https://github.com/OpenMathLib/OpenBLAS/

  GCC runtime library (libgfortran)      GPL-3.0-or-later WITH GCC-exception-3.1
                                         https://gcc.gnu.org/git/?p=gcc.git;a=tree;f=libgfortran

  openblas-libs (packaging)              BSD-2-Clause
                                         https://github.com/MacPython/openblas-libs

The libgfortran runtime is covered by the GCC Runtime Library Exception, which
permits redistribution as part of a larger work under other terms; this is the
same basis on which NumPy and SciPy ship it in every binary wheel.
