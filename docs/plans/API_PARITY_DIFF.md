Regenerate with the commands in `docs/plans/API_DIFF_GAP.md` §10, then `validate_findings.py` and this tool.

Each entry is one C# spelling of one NumPy API, written as a patch: `-` is what must go, `+` what must come, and the context lines give NumPy's signature (the target), the overload that stays (the closest one) and what the compiler refuses today. The marks: **O** several overloads (NumPy has one), **M** a NumPy parameter no overload offers, **X** a parameter NumPy does not have, **T** a dtype as `NPTypeCode` / `Type` (◇: picked by a generic type argument), **L** `null` refused for NumPy's None (◐ C# 12 only, ◦ only a `Shape` refuses it and `default` binds), **Q** a sequence of integers refused, **B** a NumPy-style call that does not compile.
