# Code of Conduct

Life Arcade is part of NumSharp and does not maintain a separate conduct policy.
Participation in this example's issues, pull requests, reviews, and other
project spaces is governed by the upstream
[NumSharp Contributor Covenant Code of Conduct](https://github.com/SciSharp/NumSharp/blob/master/CODE_OF_CONDUCT.md).

Use the scope and enforcement route stated in that policy. This pointer does not
replace or extend the upstream policy, and the packaged copy intentionally uses
an absolute link because the repository-root policy is not inside the player
archive.
