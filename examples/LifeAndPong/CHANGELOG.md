# Changelog

This file records Life Arcade changes that have not yet been represented as a
published release. It does not reconstruct or invent versioned release history;
older development can be inspected in the NumSharp Git history.

## [Unreleased]

### Added

- A focused `NumSharp.LifeAndPong.sln` for the desktop host, shared game, tests,
  NumSharp.Core, and its analyzer dependency.
- Local .NET SDK, editor, ignore, build, Windows packaging, checksum, workflow,
  and bug-reporting conventions.
- Contributor, implementation, conduct, and security guidance for the example.

### Changed

- Player and implementation documentation now describes the unified Life
  Arcade ruleset instead of the superseded separate Life-and-Pong product.
- Windows packaging includes every root-level Markdown guide, `LICENSE`, and
  the primary and ready-state previews.
