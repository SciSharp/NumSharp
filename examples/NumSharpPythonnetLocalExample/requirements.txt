# The Python side of NumSharpPythonnetLocalExample: six data science libraries, each pinned to the
# version the example was validated with. All six have binary wheels for Python 3.11, 3.12 and 3.13
# on Windows x64, Linux x64 and macOS arm64.
#
#   python -m venv .venv
#   .venv\Scripts\python -m pip install -r requirements.txt      (Windows)
#   .venv/bin/python -m pip install -r requirements.txt          (Linux, macOS)
#
# The next line adds PyTorch's own index, which has CPU-only builds. Without it, pip on Linux installs
# the CUDA build of torch together with 19 more packages (nvidia-*, cuda-*, triton) that this example
# never loads. Remove the line when you want the GPU build.
--extra-index-url https://download.pytorch.org/whl/cpu
